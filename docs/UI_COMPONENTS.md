# Radio UI 组件拆解

> 基于 `docs/assets/radio-toc-ui-reference.png`。本文定义组件边界与统一规则，供后续设计和 SwiftUI 实现复用；不代表这些界面已完成。

## 1. 组件分层

```text
设计基础
├── 颜色、文字、间距、圆角、图标、动效
通用控件
├── 电台封面、播放状态、播放按钮、收藏按钮、音量控制
业务组件
├── 电台信息、搜索框、分类切换、电台行、设置项
界面组合
├── 主播放器、电台列表、菜单栏面板、设置
```

## 2. 统一设计语言

- **颜色：**优先使用 macOS 语义色，随系统外观变化；主操作使用统一强调色，直播/失败使用各自状态色。首版没有应用内主题切换。
- **文字：**使用系统字体，统一标题、电台名称、辅助信息、状态与控件标签的层级。
- **布局：**统一间距、控件高度、圆角、分隔线和窗口内边距；播放器、列表共享同一套电台封面和按钮样式。
- **图标：**使用 SF Symbols；图标按钮必须有辅助说明，不只靠图形表达功能。
- **交互：**组件统一定义普通、悬停、按下、键盘焦点、禁用和加载状态；动效克制，尊重系统减少动态效果设置。
- **平台控件：**音量滑块、设置开关、菜单优先采用 macOS 原生控件，保持系统行为和可访问性。

## 3. 可复用组件清单

| 组件 | 职责与内容 | 关键属性/状态 |
|---|---|---|
| `StationArtworkView` | 展示电台封面；无封面时显示统一占位 | 图片、尺寸、圆角、加载/失败占位 |
| `StationMetadataView` | 展示电台名称、类型/地区、可选曲目信息 | 电台信息、紧凑/标准布局、文字截断 |
| `PlaybackStatusView` | 展示连接中、直播中、已暂停、播放失败 | 状态、简短文案、图标/动效；直播与失败不只依靠颜色 |
| `PlayPauseButton` | 播放或暂停当前电台 | 状态、尺寸、禁用状态、无障碍标签 |
| `FavoriteButton` | 收藏/取消收藏当前电台 | 是否收藏、尺寸、操作回调 |
| `VolumeControl` | 调节音量、静音/取消静音 | 当前音量、静音状态、紧凑/完整布局 |
| `StationSearchField` | 输入并清除搜索词 | 搜索词、占位提示、清除操作、焦点状态 |
| `StationCategoryPicker` | 在推荐、收藏、全部之间切换 | 当前分类、分类数量（可选） |
| `StationRowView` | 列表中的电台入口 | 封面、电台信息、当前台状态、收藏操作、选中/悬停状态 |
| `SettingRow` | 展示设置名称、说明和原生开关/选择控件 | 标题、说明、控件、当前值、禁用状态 |
| `EmptyStateView` | 展示空收藏、无搜索结果等反馈 | 标题、说明、可选操作（如重试/清除搜索） |

所有业务组件通过属性接收状态、通过回调发出操作；播放逻辑、收藏存储和窗口导航不写入纯展示组件。主播放器与菜单栏复用同一组播放/收藏/音量控件，允许使用不同尺寸和布局。

## 4. 界面组合

| 界面 | 主要组件组合 |
|---|---|
| 主播放器 | `StationArtworkView` + `StationMetadataView` + `PlaybackStatusView` + `PlayPauseButton` + `FavoriteButton` + `VolumeControl` + 电台列表入口 |
| 电台列表 | `StationSearchField` + `StationCategoryPicker` + 筛选入口 + `StationRowView` + `EmptyStateView` |
| 菜单栏面板 | 紧凑 `StationMetadataView` + `PlaybackStatusView` + `PlayPauseButton` + `VolumeControl` + `FavoriteButton` + 设置入口 |
| 设置 | 通用分组 + `SettingRow`；外观跟随 macOS |

## 5. 组件验收规则

- 同一电台在不同界面使用相同封面裁切、名称和元信息规则。
- 同一播放状态在不同界面含义一致；状态变化立即同步。
- 相同操作使用相同图标、标签和反馈；紧凑布局只改变尺寸，不改变语义。
- 图标按钮可通过键盘访问，并提供 VoiceOver 标签；滑块和开关保留原生键盘操作。
- 缺图、长名称、缺少元信息、加载中和失败均有统一回退表现。
